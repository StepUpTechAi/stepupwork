# StepUpWork for Claude

Connects Claude to your StepUpWork workshop: the workshop's tools through its MCP server, two short skills, and, in Claude Code, a pane beside the chat.

Install it in a Claude Code session:

```
/plugin install stepupwork --marketplace StepUpTechAi/stepupwork
```

Press Connect on the plugin (or sign in from `/mcp`); there is no address to set.

- `/stepupwork` opens the pane: your ticket and its train, ready work with Assign, your acceptance checklist, and Jen's questions to answer in place.
- While Jen's question waits, a "Jen asks" row above the prompt takes a quick reply, or opens the pane on it.
- `/stepupwork assign KEY` assigns a ticket to you.
- Say "hey Jen" in any chat to ask for your next ticket, answer Jen's questions or ask what blocks a train.

The workshop holds the rules; the plugin only shows and calls.
